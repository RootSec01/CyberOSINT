The tools an AI agent is given can change without anyone noticing. Raqeeb notices. الأدوات التي تُعطى لوكيل الذكاء الاصطناعي قد تتغيّر دون أن يلاحظ أحد. رقيب يلاحظ.

Raqeeb reads what Model Context Protocol servers declare to AI agents, compares it with the release the publisher actually shipped, and raises an alert when a server drifts or was altered. It never invokes a dangerous tool. يقرأ رقيب ما تُعلنه خوادم بروتوكول سياق النموذج (MCP) لوكلاء الذكاء الاصطناعي، ويقارنه بالإصدار الذي نشره المطوّر فعلاً، وينبّه عندما ينحرف الخادم أو يُعبث به. ولا يستدعي أي أداة خطرة أبداً.

The problemالمشكلة

AI agents reach real systems through MCP. A server lists the tools an agent may call: run a command, query a database, read a file. Port and CVE scanners can tell you the server is reachable. They cannot tell you what an agent connected to it is able to do, or that the answer changed after last week's redeploy. A single edited tool description is enough to steer an agent, and nothing in the network traffic looks unusual. يصل وكلاء الذكاء الاصطناعي إلى الأنظمة الحقيقية عبر MCP. يعرض الخادم الأدوات التي يحق للوكيل استدعاؤها: تشغيل أمر، أو استعلام قاعدة بيانات، أو قراءة ملف. ماسحات المنافذ والثغرات تخبرك أن الخادم متاح، لكنها لا تخبرك بما يستطيع الوكيل المتصل به فعله، ولا بأن ذلك تغيّر بعد آخر تحديث. يكفي تعديل وصف أداة واحدة لتوجيه الوكيل، دون أن يبدو أي شيء غريباً في حركة الشبكة.

How Raqeeb worksكيف يعمل رقيب

  1. Readيقرأ It asks each server for its tool list, the same request an agent makes, and records every name, description and argument. يطلب من كل خادم قائمة أدواته، بالطلب نفسه الذي يرسله الوكيل، ويسجّل كل اسم ووصف ومُدخل.
  2. Compareيقارن It checks the list against a library of what 30 widely used npm packages shipped in every release, and against the server's own earlier scans. يطابق القائمة مع مكتبة لما شحنته 30 حزمة npm واسعة الاستخدام في كل إصداراتها، ومع فحوصات الخادم السابقة.
  3. Alertينبّه A changed or injected tool becomes a finding with the exact text that differs, ready to be opened as a case and reported. تتحوّل الأداة المعدّلة أو المحقونة إلى ملاحظة تعرض النص المختلف بدقة، جاهزة لفتح قضية وإصدار تقرير.

Measured, not estimatedأرقام مقيسة لا تقديرية

83.3% of held-out MCPTox poisonings detected (215 of 258), on servers never used during development من حالات التسميم في MCPTox المحجوبة اكتُشفت (215 من 258)، على خوادم لم تُستخدم أثناء التطوير
0 false alarms on 634 clean tool declarations from the same held-out set إنذارات كاذبة على 634 تعريف أداة سليم من المجموعة المحجوبة نفسها
706 npm releases of 30 MCP packages installed and read to build the reference library إصداراً من 30 حزمة MCP على npm ثُبّتت وقُرئت لبناء المكتبة المرجعية
6.3% of 301 public registry servers changed what they declare within two days (19 servers) من 301 خادم في السجل العام غيّرت ما تعلنه خلال يومين (19 خادماً)

Every figure is reproducible from the repository. Live servers are reported only in aggregate and none is named. كل رقم هنا قابل لإعادة الإنتاج من المستودع. تُعرض الخوادم الحية بأرقام إجمالية فقط ولا يُسمّى أي منها.
