Your AI agent trusts every word its tools tell it. Raqeeb checks them for you. وكيل الذكاء الاصطناعي يثق بكل كلمة في وصف أدواته. رقيب يتحقّق منها نيابةً عنك.

Raqeeb reads what Model Context Protocol (MCP) servers declare to AI agents, compares it with the release the publisher actually shipped, and alerts you the moment a server drifts or is tampered with, without ever invoking a dangerous tool. يقرأ رقيب ما تُعلنه خوادم بروتوكول سياق النموذج (MCP) لوكلاء الذكاء الاصطناعي، ويطابقه مع الإصدار الذي نشره المطوّر فعلاً، وينبّهك فور انحراف الخادم أو العبث به، دون أن يستدعي أي أداة خطرة.

The threatالخطر

One sentence is enough.جملة واحدة تكفي.

An attacker doesn't need to break in. Rewriting a tool's description is enough: the user never sees it, the network traffic looks normal, and the agent does what it says. لا يحتاج المهاجم إلى اختراق النظام؛ يكفيه أن يعيد كتابة وصف أداة واحدة. المستخدم لا يرى هذا الوصف، وحركة الشبكة تبدو طبيعية، والوكيل ينفّذ ما فيه.

What scanners seeما تراه الماسحات التقليدية

An open port and a healthy service. Nothing to report.منفذ مفتوح وخدمة تعمل بشكل سليم، ولا شيء يستدعي التنبيه.

What Raqeeb seesما يراه رقيب

A tool that no longer matches anything its publisher ever shipped, and the exact words that changed.أداة لم تعد تطابق أي إصدار نشره مطوّرها، والكلمات التي تغيّرت بالضبط.

How it worksآلية العمل

Read. Compare. Alert.يقرأ، يطابق، ينبّه.

  1. Readيقرأ It asks each server for its tool list with the same request an agent sends, and records every name, description and argument. يطلب من كل خادم قائمة أدواته بالطلب ذاته الذي يرسله الوكيل، ويسجّل اسم كل أداة ووصفها ومُدخلاتها.
  2. Compareيطابق It checks the list against a reference library of every release of 30 widely used MCP packages on npm, and against the server's own earlier scans. يطابق القائمة مع مكتبة مرجعية تضم كل إصدارات 30 حزمة MCP واسعة الانتشار على npm، ومع فحوصات الخادم السابقة.
  3. Alertينبّه Every changed or injected tool becomes an alert that shows the differing text word for word, ready to open as a case and report. تتحوّل كل أداة معدّلة أو محقونة إلى تنبيه يعرض النص المختلف حرفياً، جاهزاً لفتح قضية وإصدار تقرير.

  • Never names a live serverلا يسمّي أي خادم حي

Resultsالنتائج

Measured, not estimated.أرقام مَقيسة، لا تقديرات.

83.3% of poisoned tool descriptions in the MCPTox benchmark detected (215 of 258), on servers never used during development من أوصاف الأدوات المسمومة في معيار MCPTox كُشفت (215 من 258)، على خوادم لم تُستخدم أثناء التطوير
0 false alarms across 634 clean tool declarations from the same held-out set إنذارات كاذبة على 634 تعريفاً سليماً للأدوات من المجموعة المحجوبة نفسها
706 npm releases of 30 MCP packages installed and read to build the reference library إصدارات من 30 حزمة MCP على npm ثُبّتت وقُرئت لبناء المكتبة المرجعية
6.3% of 301 public registry servers changed their tool definitions within two days (19 servers) من 301 خادم في السجل العام غيّرت تعريفات أدواتها خلال يومين (19 خادماً)

Every figure can be reproduced from the repository. Live servers are reported in aggregate only, and none is named. يمكن إعادة إنتاج كل رقم هنا من المستودع. نعرض نتائج الخوادم الحية مجمّعةً فقط، ولا نسمّي أي خادم.
