In shortباختصار

Like checking the seal before you open the box.كأنك تتأكد من الختم قبل فتح العلبة.

1

AI agents use toolsالوكيل يستخدم أدوات

An AI assistant can read files, run commands or query data through tools, and each tool comes with a short description of what it does.يستطيع مساعد الذكاء الاصطناعي قراءة الملفات وتنفيذ الأوامر والبحث في البيانات عبر أدوات، ولكل أداة وصف قصير يشرح ما تفعله.

2

The agent believes the descriptionالوكيل يصدّق الوصف

Whatever that description says, the agent follows. If someone quietly edits it, the agent obeys the new words.الوكيل ينفّذ ما يقوله الوصف. فإن عدّله أحدٌ في الخفاء، أطاع الوكيل الكلمات الجديدة.

3

Raqeeb checks the sealرقيب يتحقق من الختم

Raqeeb keeps the original descriptions as their publishers released them, and compares them with what each server says today.يحتفظ رقيب بالأوصاف الأصلية كما نشرها مطوّروها، ويقارنها بما يقوله كل خادم اليوم.

The threatالخطر

One sentence is enough.جملة واحدة تكفي.

An attacker doesn't need to break in. Rewriting one tool's description is enough: the user never sees it, the network looks normal, and the agent does what it says. لا يحتاج المهاجم إلى اختراق النظام؛ يكفيه أن يعيد كتابة وصف أداة واحدة. المستخدم لا يرى هذا الوصف، والشبكة تبدو طبيعية، والوكيل ينفّذ ما فيه.

What ordinary scanners seeما تراه الماسحات التقليدية

An open port and a healthy service. Nothing to report.منفذ مفتوح وخدمة تعمل بشكل سليم، ولا شيء يستدعي التنبيه.

What Raqeeb seesما يراه رقيب

A tool that no longer matches anything its publisher released, and the exact words that changed.أداة لم تعد تطابق أي إصدار نشره مطوّرها، والكلمات التي تغيّرت بالضبط.

How it worksآلية العمل

Read. Compare. Alert.يقرأ، يطابق، ينبّه.

  1. Readيقرأ It asks each server for its list of tools, exactly as an AI agent would, and saves every name and description. يطلب من كل خادم قائمة أدواته كما يطلبها وكيل الذكاء الاصطناعي تماماً، ويحفظ اسم كل أداة ووصفها.
  2. Compareيطابق It compares that list with the originals: every release of 30 popular MCP packages, plus the server's own earlier scans. يطابق القائمة مع النسخ الأصلية: كل إصدارات 30 حزمة MCP شائعة، إضافةً إلى فحوصات الخادم السابقة.
  3. Alertينبّه If anything changed, it raises an alert that shows the exact words, ready to open as a case and report. إن تغيّر أي شيء، يُطلق تنبيهاً يعرض الكلمات المتغيّرة بالضبط، جاهزاً لفتح قضية وإصدار تقرير.
  • Never runs a dangerous toolلا يشغّل أي أداة خطرة
  • Never names a live serverلا يسمّي أي خادم حي
  • Open source, MIT licenceمفتوح المصدر برخصة MIT

Resultsالنتائج

Measured, not estimated.أرقام مَقيسة، لا تقديرات.

83.3% of poisoned tool descriptions in the MCPTox benchmark caught (215 of 258), on servers never used while building the detector من أوصاف الأدوات المسمومة في معيار MCPTox كُشفت (215 من 258)، على خوادم لم تُستخدم أثناء بناء الكاشف
0 false alarms on 634 clean tool descriptions إنذارات كاذبة على 634 وصفاً سليماً للأدوات
706 original releases of 30 MCP packages collected as the reference إصدارات أصلية من 30 حزمة MCP جُمعت لتكون المرجع
6.3% of 301 public servers changed their tools within just two days (19 servers) من 301 خادم عام غيّرت أدواتها خلال يومين فقط (19 خادماً)

Every figure can be reproduced. Live servers are reported in aggregate only, and none is named. يمكن إعادة إنتاج كل رقم هنا. نعرض نتائج الخوادم الحية مجمّعةً فقط، ولا نسمّي أي خادم.
